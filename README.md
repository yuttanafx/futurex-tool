# เทมเพลตปักตะกร้า (Next.js)

เว็บเก็บเทมเพลตสินค้า (ชื่อ ราคา แคปชัน แฮชแท็ก) สำหรับโพสต์คลิป TikTok Shop กดคัดลอกครั้งเดียว
มีระบบสมาชิกและแอดมิน แต่ละบัญชีเห็นเฉพาะเทมเพลตของตัวเอง

ตัวเว็บไม่ได้ปักตะกร้าแทนคนและไม่ได้เชื่อมกับบัญชี TikTok ขั้นสุดท้ายต้องกดเพิ่มสินค้าในแอป TikTok เอง

## เริ่มใช้งาน

```bash
npm install
cp .env.example .env.local      # แล้วแก้ค่าในไฟล์
npm run dev                     # เปิด http://localhost:3000
```

ค่าที่ต้องตั้งใน `.env.local`

| ตัวแปร | ความหมาย |
|---|---|
| `AUTH_SECRET` | คีย์เซ็นคุกกี้ ยาวอย่างน้อย 32 ตัว สร้างด้วย `openssl rand -base64 48` |
| `ADMIN_EMAIL`, `ADMIN_PASSWORD` | แอดมินคนแรก สร้างอัตโนมัติตอนรันครั้งแรกถ้ายังไม่มีแอดมิน |
| `ALLOW_REGISTRATION` | `true` ให้คนสมัครเอง, `false` ให้แอดมินสร้างบัญชีให้เท่านั้น |
| `DATABASE_URL` | Postgres connection string (บังคับ) ตารางสร้างให้เองครั้งแรก |

## สองโหมดการโพสต์

| โหมด | สถานะ | ทำงานอย่างไร |
|---|---|---|
| `manual` | ใช้ได้ทันที (ค่าเริ่มต้น) | กดคัดลอกในเว็บ แล้ววางและเพิ่มสินค้าในแอป TikTok เอง |
| `tiktok` | ยังไม่เปิด (ช่องเสียบไว้แล้ว) | ปุ่ม "ส่งไป TikTok" ที่การ์ดสินค้า ส่งผ่าน API ของ TikTok |

ตั้งโหมดด้วย `PUBLISH_MODE` ใน `.env.local` ถ้าตั้งเป็น `tiktok` แต่ยังไม่พร้อม ระบบถอยกลับเป็น `manual` เอง
และหน้าแอดมินแสดงสถานะให้เห็น ทุกครั้งที่กดส่งจะบันทึกลงตาราง `publish_jobs` (queued / done / failed)

ส่วนที่ต้องทำเมื่อมี API อยู่ในคอมเมนต์ที่ต้นไฟล์ `lib/publishers/tiktok.js` สรุปคือ
ตรวจเอกสาร TikTok ว่ารองรับการแนบสินค้าหรือไม่ → เพิ่มตารางเก็บโทเคนของสมาชิก (เข้ารหัส) และหน้าเชื่อมบัญชีด้วย OAuth →
เขียน `publish()` → ตั้ง `IMPLEMENTED = true` และใส่คีย์ ตอนนี้ยังไม่ได้เขียนการเรียก API จริง

## ช่องรายละเอียดสินค้า

แต่ละเทมเพลตมีช่อง รายละเอียดสินค้า (ส่วนผสม ขนาด วิธีใช้), เลข อย. และลิงก์หน้าสินค้าต้นทาง
ปุ่ม "คัดลอกทั้งหมด" รวมชื่อ ราคา แคปชัน เลข อย. (ถ้ามี) และแฮชแท็ก ส่วนรายละเอียดมีปุ่มคัดลอกแยก

## ใส่สินค้าตัวอย่างจากร้าน "ร้านของฉัน"

เมื่อมีบัญชีสมาชิกแล้ว (ตั้ง `DATABASE_URL` ใน `.env.local` ให้ชี้ฐานข้อมูลเดียวกับที่เว็บใช้) รัน `npm run seed:products -- อีเมลสมาชิก`
จะเพิ่มสินค้า 7 รายการ (ชื่อ ราคา และรายละเอียดตามหน้าร้าน พร้อมลิงก์ต้นทาง) เข้าเทมเพลตของบัญชีนั้น
รันซ้ำได้ รายการที่มีอยู่แล้วแต่ยังไม่มีรายละเอียดจะถูกเติมให้ รายการอื่นถูกข้าม
แคปชันเขียนแบบกลาง ๆ และรายละเอียดเก็บเฉพาะข้อเท็จจริง (ส่วนผสม ขนาด วิธีทาน) ไม่เอาข้อความสรรพคุณ
รหัสสินค้าในหน้าร้านเป็น SAMPLE-01 ถึง SAMPLE-07 อาจเป็นข้อมูลตัวอย่าง ควรเทียบกับฉลากจริง
ควรเพิ่มเลข อย. และตรวจข้อความให้ตรงกฎโฆษณาอาหารเสริมก่อนโพสต์

## สิทธิ์

- **สมาชิก**: เพิ่ม แก้ไข ลบ คัดลอกเทมเพลตของตัวเอง
- **แอดมิน**: เพิ่มสมาชิก ตั้งรหัสผ่านใหม่ ระงับ/เปิดใช้งาน เลื่อน/ลดบทบาท ลบบัญชี
  แอดมินแก้สถานะหรือลบบัญชีตัวเองไม่ได้ เพื่อไม่ให้ระบบไม่เหลือแอดมิน
- บัญชีที่ถูกระงับจะใช้งานไม่ได้ทันที เพราะระบบเช็กฐานข้อมูลทุกครั้งที่เปิดหน้า

## โครงสร้าง

```
middleware.js          ด่านแรก: ต้องล็อกอิน, /admin ต้องเป็นแอดมิน
lib/db.js              Postgres (pg) + สร้างตาราง + สร้างแอดมินคนแรก
lib/token.js           เซ็น/ตรวจ JWT (ใช้ใน middleware ได้)
lib/auth.js            session, requireUser, requireAdmin, bcrypt
app/login, app/register
app/dashboard          เทมเพลตของฉัน (TemplateManager.jsx = ฝั่งหน้าเว็บ)
app/admin              จัดการสมาชิก
```

## ก่อนขึ้นใช้งานจริง

- โค้ดชุดนี้เขียนแล้วแต่ยังไม่เคยรันทดสอบ ลอง `npm install && npm run dev` แล้วไล่เช็กล็อกอิน สมัคร เพิ่มเทมเพลต และหน้าแอดมิน
- ฐานข้อมูลเป็น Postgres ใช้ได้กับ Vercel (แนะนำ Neon จาก Storage ใน Vercel), Supabase, Railway ฯลฯ ต้องตั้ง `DATABASE_URL`
- ยังไม่มีการจำกัดจำนวนครั้งที่ลองล็อกอินผิด ควรเพิ่ม rate limit ก่อนเปิดให้คนทั่วไปสมัคร
- ใช้ HTTPS เสมอ (คุกกี้ตั้ง `secure` อัตโนมัติเมื่อรันแบบ production)
- ยังไม่มีระบบลืมรหัสผ่านทางอีเมล ตอนนี้แอดมินตั้งรหัสใหม่ให้
